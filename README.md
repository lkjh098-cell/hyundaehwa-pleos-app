# 현대화 · Pleos Connect 네이티브 앱 0.6.0-rc7

시연영상의 동작을 실제 Android/Pleos 앱에 이식한 검수 버전입니다. WebView로 시연사이트를 띄우거나 순정 내비 지도를 복제하지 않습니다. 순정 내비와 나란히 쓰는 창 배치는 Pleos 시스템이 맡습니다.

## 반영한 흐름

- 공식 좌석 신호를 표시하고, 실제 P 정차·속도 0·UX 허용 상태에서 관계 선택 팝업을 엽니다. 관계 선택 후 화두 안내가 시작되며 관계를 화면에 유지합니다. 센서로 관계나 나이를 추측하지 않습니다.
- 처음 관계를 선택하면 음성 답변·침묵 감지 사용을 묻습니다. 사용자가 동의하고 마이크 권한을 허용한 경우에만 앱이 전면에서 소리 크기를 측정합니다. 소리 크기 측정용 PCM은 메모리에서 즉시 폐기하며 파일로 저장하지 않습니다.
- 지역이 바뀌면 침묵이나 마이크 상태를 기다리지 않고 진입 안내 뒤 해당 지역 콘텐츠를 제공합니다. 목적지 날씨·계획 화두는 별도의 기본 5분 침묵 조건을 사용합니다. 설정에서 1·3·5·10·15분 및 자동·상·중·하 난이도, 어린이 동승 여부를 선택할 수 있습니다. 소리 입력이 없거나 오래됐을 때 이를 침묵으로 간주하지 않습니다.
- 음악·라디오 재생 확인 시 새 화두를 보류합니다. 외부 라디오를 기기가 보고하지 않는 경우 설정의 외부 미디어 보류를 사용해야 합니다. AEC를 제공하는 기기에서는 안내 도중 높은 소리 입력을 받으면 중단하고, 조용해진 뒤 남은 해설을 이어갑니다. 이는 대화 내용을 분류하는 기능이 아니며 실차 소음 환경의 정확도는 별도 검증 대상입니다.
- 목적지 날씨는 설정에서 별도 동의 후 실제 도착 예상 시점의 MET Norway 예보를 조회합니다. 유효 예보가 준비되면 첫 침묵 화두에 우선합니다. 예보가 없을 때 수치나 날씨를 만들지 않습니다.
- 실제 현재 좌표의 행정구역을 판정합니다. 지역이 바뀌어도 진행 중 질문·정답 해설을 유지합니다. 번호·보기 이름·밸런스게임 전자/후자 답변을 기기 내 음성으로 받고, 답변 말풍선과 전체 정답 해설을 제공합니다. 무응답 공개는 질문 음성 재생 완료 후 8초를 기준으로 합니다.
- 실제 분기·진출·터널 신호의 안전 구간에서는 안내를 중단합니다. 내비 음성 및 오디오 포커스를 우선하고, 허용되는 경우 안전 모드 진입을 짧게 알립니다. 구간이 끝나면 보류한 해설을 이어갑니다.
- 연속 1시간 운전 시 휴식을 제안합니다. 실제 경로 앞쪽으로 확인된 휴게소만 후보로 사용합니다. 현재 검증된 입구 목록은 망향휴게소·천안호두휴게소 부산방향 두 곳입니다. 모든 경로에 전국 휴게소 두 곳을 보장하지 않습니다.
- 음성으로 휴게소 선택 → 경유 확인 질문 → 별도 명시적 동의 → NaviHelper 경유지 추가 요청 순서입니다. 요청 수락과 실제 경유지 적용 확인을 구분합니다. 화면 선택은 정차 제한을 유지합니다.
- 실제 도착 신호가 오면 ‘목적지에 도착했어요. 즐거운 시간 보내세요.’로 끝맺습니다.
- 승인된 네이비 H 로고·한국어 안내·둥근 메시지 카드·Pretendard 서체를 사용합니다.

## 빌드

Android SDK를 설치하고 local.properties의 sdk.dir을 본인 환경에 설정합니다. local.properties·서명키·암호·캐시는 소스 배포에 포함하지 않습니다.

`./gradlew :core:test :app:assembleDebug :app:assembleDebugAndroidTest`

`python3 scripts/sign_release.py`는 이 Mac의 기존 키체인 항목과 로컬 서명키만 사용합니다. 다른 환경에서는 본인 서명 구성을 안전하게 제공해야 합니다. 설치된 Gradle을 쓰는 경우 HYUNDAEHWA_GRADLE_BIN을 지정할 수 있습니다.

## 남은 외부 검증·승인

- 실제 차량의 마이크·AEC·한국어 인식 정확도, 라디오 상태, 길 안내 우선순위 및 전국 경로의 휴게소 입구 검증
- OEM Gleo 수신 패키지·인증서·호출자 규격, 스키마 승인과 활성화. 기본 설정은 미승인 수신자에게 데이터를 전송하지 않습니다. Gemini 릴레이는 출시에서 비활성입니다. 따라서 자유 대화의 완전한 Gleo 연동을 완료했다고 표시하지 않습니다.
- 마켓 심사, 공개 개인정보처리방침·약관·운영자 정보·필요 등급 증빙

검사 결과는 동봉 검증결과.json과 에뮬레이터 로그를 참조하세요. 빌드·에뮬레이터 통과는 실제 차량 출시 승인이나 모든 음성의 물리적 청취 검증을 대신하지 않습니다.

## 시연 패널 정리 · rc2

이전 버전의 가로 설정 사이드바를 없애고 영상처럼 하나의 대화 패널로 구성했습니다. 네이비 브랜드 헤더, 지역 문구, 연한 메시지 카드, 사람 답변의 네이비 말풍선, 하단 입력·조용히 가기를 유지합니다. 관계 선택과 설정은 네이비 제목의 별도 팝업입니다. 상단에 실제 정차/침묵 시간/마이크 설정/안전 및 미디어 보류 상태를 표시하고, 마이크 미동의 상태를 누르면 기존 동의 절차로 돌아갑니다. 목적지가 없을 때는 순정 내비로 연결하는 버튼을 표시합니다.

에뮬레이터 순정 지도는 현대화 앱을 닫고 단독 실행해도 도로 타일이 비어 있습니다. 소프트웨어 그래픽은 이 이미지에서 전체 화면 렌더링 문제를 일으켰고, 하드웨어 그래픽/Vulkan 비활성으로 일반 화면은 복구했으나 지도 타일 표시 성공은 아직 확인하지 못했습니다. 공개 서울시청 좌표를 시험 입력했으며 사용자의 실제 위치는 사용하지 않았습니다. 지도 렌더링과 실제 검색·경로 계산은 완료 항목이 아닙니다. 이 앱은 이를 복제 지도나 가짜 주행으로 대신하지 않습니다.

현재 원격 소스 저장소: https://github.com/lkjh098-cell/hyundaehwa-pleos-app (비공개)

## 내비 복귀 · rc3

관계를 아직 선택하지 않은 채 내비로 이동했다 돌아오면 관계 팝업을 다시 엽니다. 같은 화면에서 사용자가 직접 닫은 팝업을 매 초 강제로 다시 띄우지는 않습니다. 실제 OEM 내비 Activity로 이동·복귀하는 화면 테스트로 검증합니다.


## 시연 인터페이스·콘텐츠 일치 · rc4

- 최신 보존된 v46 시연 소스의 데이터와 APK 자산을 재대조했습니다. 246개 지역·위치 기반 퀴즈 2,354개·생활형 밸런스게임 505개가 일치하며, 모든 지역에 상·중·하 퀴즈가 있습니다. 신규 사실 전수 조사를 수행했다는 의미는 아닙니다.
- 흰색 질문 카드에 유형·제목·현재 지역·문제를 구분해 표시합니다. 선택지를 음성 제어보다 먼저 배치하고, 선택 후 네이비 선택 표시와 사람 답변 말풍선·전체 해설을 유지합니다.
- Pretendard와 승인된 H 로고를 유지하며, 작은 글자·버튼을 키우고 관계·설정 팝업과 고정 입력창의 크기를 통일했습니다.
- 지역 이야기는 같은 행정구역에 속한 장소 설명과 구체적인 생활 선택지를 사용합니다. 목적지 화두는 시연 소스의 8가지 유형·42개 선택지 조합을 사용합니다. 이 콘텐츠 생성 함수의 보강은 자동 노출 정책을 바꾼 것이 아닙니다.
- 실제 Pleos 시스템의 분할 창에서 순정 내비와 나란히 배치할 수 있습니다. 순정 내비 배경 지도 공백은 현대화 미설치 새 공식 AVD에서도 재현됐으며, 검색·경로선은 동작하지만 배경 도로망은 아직 미해결입니다. 이전 기록의 '경로 계산 미검증'은 현재 진단에서는 갱신됐습니다. APK가 가짜 지도로 대신하지 않습니다.
- 문항 렌더 검사는 실제 번들 문항을 검사 도구가 화면에 올려 배치·말풍선·전체 해설을 확인합니다. 이 검사는 실제 자동 주행이나 사람 발화 인식 시험이 아닙니다.


## 창 크기 변경 중 선택 복원 · rc5

창 크기를 바꾸며 정차·UX 신호가 일시적으로 보류되어 관계 팝업을 닫은 경우, 관계를 아직 고르지 않았다면 실제 허용 상태가 복구된 뒤 선택창을 다시 엽니다. 정차 중 사용자가 직접 닫은 팝업을 반복해서 여는 동작은 추가하지 않습니다.


## 음성 준비와 초기 설정 분리 · rc6

음성 안내를 켠 실제 앱에서도 인사말 준비나 오디오 포커스 대기가 관계 선택 팝업을 막지 않습니다. 실제 정차·UX 허용·명시적 관계 선택 조건은 유지하며 음성 사용 설정을 켠 상태로 초기 팝업·실제 가족 선택·설정 동작을 검사합니다.


## 지역·음성·안전 순서 일치 · rc7

- 진입 안내가 실제로 완료된 지역의 질문만 표시합니다. 안내 중 A에서 B로 이동해도 A 질문·해설을 끝낸 뒤 B 안내를 이어갑니다.
- 안내를 시작할 때 지역·문항·관계·난이도를 고정하여 설정 변경이나 데이터 새로고침이 진행 중 질문을 바꾸지 않습니다. 카드를 실제 표시한 뒤에만 사용 기록과 3:1 순서 슬롯을 소비합니다.
- 안전·미디어·앱 배경 전환으로 중단한 안내는 남은 문장부터 다시 시작합니다. 마이크 미동의나 소리 입력 미확인이 음성 재개를 영구적으로 막지 않습니다.
- 두 보기 문항의 앞의 거·뒤의 거·첫번·처음 거 등 상대 답변 표현을 보강했습니다. 충돌·부정·인용 발화는 임의 선택하지 않습니다.
- 질문 전환 중 음성 입력 상태 콜백으로 화면을 재귀적으로 다시 그리던 종료 오류를 수정했습니다.
- 웹의 자동차 장식 패널은 제거했습니다. APK에 표시되는 실제 시스템 DrivingView는 현대화가 그린 화면이 아니며 변경하지 않습니다.
- 에뮬레이터의 실제 음성 콜백을 사용한 지역 A→B·안전 중단/재개 검사를 통과했습니다. 이 검사의 위치·안전 신호는 명시적인 시험 입력이며, 실차 GPS·물리적 청취·한국어 인식 정확도의 검증을 뜻하지 않습니다.
- 목적지 음성 후보 검색·확인은 웹과 동일한 앱 내부 흐름이 아닙니다. APK는 순정 내비에서 목적지를 정하고 공식 SDK에서 받은 결과를 사용합니다. 자유 Gleo 대화 승인 및 실제 사람 음성 검증은 여전히 남아 있습니다.

문항 로더는 정확한 지역 코드별 색인을 사용합니다. 준비 중/실패 상태를 표시하며 로딩은 백그라운드에서 수행합니다. 공식 에뮬레이터의 별도 새 프로세스 검사에서 첫 패널 2,476ms, 메인 스레드 응답 1ms, 데이터 준비 12,897ms를 관찰했습니다. 이는 해당 시험 환경의 측정이며 실차 성능 보장은 아닙니다.

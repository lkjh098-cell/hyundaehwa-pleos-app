# 현대화 · Pleos Connect 네이티브 앱

현대화는 현재 지역의 이야기와 퀴즈를 동승자에게 안내하는 Android/Pleos 앱입니다. 차량·위치·내비게이션 신호에 따라 안내 시점을 정하고, 순정 내비와 나란히 쓰는 창 배치는 Pleos 시스템에 맡깁니다. WebView나 자체 내비 지도를 사용하지 않습니다.

## 주요 동작

- 공식 좌석 신호를 표시하고, 실제 P 정차·속도 0·UX 허용 상태에서 관계 선택 팝업을 엽니다. 관계 선택 후 화두 안내가 시작되며 관계를 화면에 유지합니다. 센서로 관계나 나이를 추측하지 않습니다.
- 처음 관계를 선택하면 음성 답변·침묵 감지 사용을 묻습니다. 사용자가 동의하고 마이크 권한을 허용한 경우에만 앱이 전면에서 소리 크기를 측정합니다. 소리 크기 측정용 PCM은 메모리에서 즉시 폐기하며 파일로 저장하지 않습니다.
- 지역이 바뀌면 침묵이나 마이크 상태를 기다리지 않고 진입 안내 뒤 해당 지역 콘텐츠를 제공합니다. 목적지 날씨 안내는 별도의 기본 5분 침묵 조건을 사용합니다. 설정에서 1·3·5·10·15분 및 자동·상·중·하 난이도, 어린이 동승 여부를 선택할 수 있습니다. 소리 입력이 없거나 오래됐을 때 이를 침묵으로 간주하지 않습니다.
- 음악·라디오 재생 확인 시 새 화두를 보류합니다. 외부 라디오를 기기가 보고하지 않는 경우 설정의 외부 미디어 보류를 사용해야 합니다. AEC를 제공하는 기기에서는 안내 도중 높은 소리 입력을 받으면 중단하고, 조용해진 뒤 남은 해설을 이어갑니다. 이는 대화 내용을 분류하는 기능이 아니며 실차 소음 환경의 정확도는 별도 검증 대상입니다.
- 목적지 날씨는 설정에서 별도 동의 후 실제 도착 예상 시점의 MET Norway 예보를 조회합니다. 유효 예보가 준비되면 첫 침묵 화두에 우선합니다. 예보가 없을 때 수치나 날씨를 만들지 않습니다.
- 실제 현재 좌표의 행정구역을 판정합니다. 지역이 바뀌어도 진행 중 질문·정답 해설을 유지합니다. 번호·보기 이름·밸런스게임 전자/후자 답변을 기기 내 음성으로 받고, 답변 말풍선과 전체 정답 해설을 제공합니다. 무응답 공개는 질문 음성 재생 완료 후 8초를 기준으로 하며, 음성 입력을 사용할 때는 마이크 준비가 확인된 뒤 응답 시간을 계산합니다. 질문이 새로 재생 완료되면 이전 답변 시도의 실패 기록을 초기화하고, 마이크 준비 중과 실제 듣는 중을 구분해 표시합니다. 입력 없이 음성 인식이 종료되면 남은 답변 시간 안에서 최대 두 번 다시 연결합니다.
- 실제 분기·진출·터널 신호의 안전 구간에서는 안내를 중단합니다. 내비 음성 및 오디오 포커스를 우선하고, 허용되는 경우 안전 모드 진입을 짧게 알립니다. 구간이 끝나면 보류한 해설을 이어갑니다.
- 연속 1시간 운전 시 휴식을 제안합니다. 실제 경로 앞쪽으로 확인된 휴게소만 후보로 사용합니다. 현재 검증된 입구 목록은 망향휴게소·천안호두휴게소 부산방향 두 곳입니다. 모든 경로에 전국 휴게소 두 곳을 보장하지 않습니다.
- 음성으로 휴게소 선택 → 경유 확인 질문 → 별도 명시적 동의 → NaviHelper 경유지 추가 요청 순서입니다. 요청 수락과 실제 경유지 적용 확인을 구분합니다. 화면 선택은 정차 제한을 유지합니다.
- 실제 도착 신호가 오면 ‘목적지에 도착했어요. 즐거운 시간 보내세요.’로 끝맺습니다.
- 네이비 H 로고·한국어 안내·둥근 메시지 카드·Pretendard 서체를 사용합니다. 관계 선택과 설정은 별도 팝업으로 제공하며, 설정 중에는 실제 정차·UX 허용 상태를 확인합니다.

## 데이터와 SDK

- 공유 콘텐츠 원본의 246개 지역, 퀴즈 2,354개, 생활형 밸런스게임 505개를 포함합니다. 데이터 출처·버전 정보는 번들에 보존합니다. 데이터 일치 검사는 개별 사실 출처의 새 전수 검증을 의미하지 않습니다.
- Vehicle 2.3.2 / vehicle-data 1.1.11 / NaviHelper 3.0.5 / navi-data 3.0.4 / SpeechToText 3.3.1 / TextToSpeech 3.3.1
- Java 17, Kotlin 2.0.21, Gradle 8.10.2, Android Gradle Plugin 8.8.2, compile/target SDK 35, min SDK 28
- 배포 버전: ai.hyundaehwa.car, 0.6.0-rc12 / versionCode 41. 기존 출시 서명키와 기기 내 음성 인식을 유지합니다. 짧은 보기 일부의 오인식 한계를 공개한 상태로 배포합니다
- 별도 검수: ai.hyundaehwa.car.releaseqa. 출시와 같은 SDK 분기·서명, 디버깅 불가. 계측 검사를 위해 코드·리소스 축소는 끄며 출시 APK와 동일한 바이너리는 아닙니다
- 개발 미리보기: ai.hyundaehwa.car.preview. 개발용 가상 신호·배속은 이 변형에만 존재

## 빌드

Android SDK를 설치하고 local.properties의 sdk.dir을 본인 환경에 설정합니다. local.properties·서명키·암호·캐시는 소스 배포에 포함하지 않습니다.

`./gradlew :core:test :app:assembleDebug :app:assembleDebugAndroidTest`

`python3 scripts/sign_release.py`는 이 Mac의 기존 키체인 항목과 로컬 서명키만 사용합니다. 다른 환경에서는 본인 서명 구성을 안전하게 제공해야 합니다. 설치된 Gradle을 쓰는 경우 HYUNDAEHWA_GRADLE_BIN을 지정할 수 있습니다.

## 남은 외부 검증·승인

- 실제 차량의 마이크·AEC·한국어 인식 정확도, 라디오 상태, 길 안내 우선순위 및 전국 경로의 휴게소 입구 검증
- OEM Gleo 수신 패키지·인증서·호출자 규격, 스키마 승인과 활성화. 기본 설정은 미승인 수신자에게 데이터를 전송하지 않습니다. Gemini 릴레이는 출시에서 비활성입니다. 따라서 자유 대화의 완전한 Gleo 연동을 완료했다고 표시하지 않습니다.
- 마켓 심사, 공개 개인정보처리방침·약관·운영자 정보·필요 등급 증빙

## 코드 구조

- `core/`: Android에 의존하지 않는 대화 상태 전이, 지역 진입 순서, 질문·해설 재개, 음성 답변 판정과 차량 신호 유효성 정책.
- `app/src/main/java/ai/hyundaehwa/car/MainActivity.kt`: 대화 패널, 사용자 설정과 플랫폼·음성 이벤트 연결.
- `app/src/main/java/ai/hyundaehwa/car/platform/`: Pleos SDK, 기기 음성 인식·재생, 행정구역 콘텐츠 로더, 목적지 예보와 Gleo 수신자 검증.
- `app/src/main/assets/`: 행정구역·문항·음성 자산과 원출처 정보. 정확한 지역 코드별 색인으로 조회하며, 로딩은 백그라운드에서 수행합니다.
- `core/src/test/`, `app/src/androidTest/`: 대화 정책 단위 검사와 Android 통합 검사.

지역 진입 때 문항·관계·난이도를 함께 고정합니다. 지역이나 설정이 바뀌어도 진행 중 질문과 해설은 유지하며, 다음 지역 안내가 먼저 끼어들지 않습니다. 화면에 실제 카드를 표시한 뒤에만 사용 기록과 콘텐츠 순서 슬롯을 소비합니다. 안전·미디어·앱 배경 전환으로 중단한 안내는 보관한 문장 위치부터 이어갑니다.

관계를 선택하지 않은 채 내비로 이동했다 돌아오면 정차·UX 허용 상태에서 선택창을 다시 엽니다. 창 크기 변경으로 설정 권한이 잠시 보류된 경우에도 같은 조건을 다시 확인합니다. 사용자가 직접 닫은 선택창은 같은 화면에서 반복해서 열지 않습니다. 음성 인사말 준비와 관계 선택은 독립적으로 처리합니다.

## 검증 범위

rc12는 짧은 보기 일부의 오인식 한계를 고지하고 사용자 승인으로 배포한 버전입니다. 마이크 소유권 경합, 준비 완료 처리와 늦게 도착하는 최종 인식 결과 처리를 수정했습니다. 공식 에뮬레이터 첫 입력 검사는 6개 중 5개 통과했으며 짧은 보기 1개는 음성 엔진 오인식으로 실패했습니다. 실제 마이크 양도 검사와 콜백 검사 9개, 코어 검사 279개 및 배포 APK 설치·실행은 통과했습니다. 출시와 동일한 SDK 분기를 쓰되 축소를 끈 QA 앱에서 음성을 검사했으며, 실차·사람 마이크와 최적화된 배포 APK의 첫 답변 인식은 검증하지 않았습니다. 현재 검사 범위와 미완료 조건은 [verification-rc12.json](docs/verification-rc12.json)에 기록합니다. 이전 배포본의 검사 결과는 [verification-rc11.json](docs/verification-rc11.json), 과거 검증은 [verification-rc7.json](docs/verification-rc7.json)에 보존합니다. 마켓 제출 조건은 [Pleos 출시 검증 항목](docs/PLEOS_RELEASE_GATES.md)을 참조하세요.

단위 검사는 정책·상태 전이를, Android 통합 검사는 주입한 SDK 콜백의 처리와 화면 처리를 확인하며, 별도의 음성 시험에서만 실제 인식 엔진을 사용합니다. 통합 검사에 주입한 지역·안전 신호는 시험 입력입니다. 문항 렌더 검사는 번들 문항의 배치·답변 말풍선·해설 표시를 확인하며 실제 주행이나 사람 발화 인식 시험을 뜻하지 않습니다.

공식 에뮬레이터에서 순정 내비의 검색·경로선은 관찰됐으나 배경 도로망 공백은 해결되지 않았습니다. 시스템 DrivingView와 지도 렌더링은 현대화 앱의 화면이 아닙니다. 목적지 선택은 순정 내비에서 수행하고 앱은 공식 SDK가 전달한 결과를 사용합니다.

빌드·에뮬레이터 통과는 실차 출시 승인, 물리적 음성 청취, 한국어 인식 정확도나 실차 성능을 보장하지 않습니다. 실제 Gleo 자유 대화 연동과 OEM 승인 상태는 위의 외부 검증 항목에 따릅니다.
